== redaction policy (LEM-144) ==
Browser screenshot capture redaction policy (best-effort, defense-in-depth): when runtime/browser evidence indicates associated page artifacts (snapshot/console/network/navigation/headers) contain known secret-like values (e.g. private key blocks, cloud/provider tokens, bearer credentials, common API key patterns), per-check screenshot duplication/capture is withheld for that check and the outcome is marked with metadata (screenshot_redacted/redaction_note). Dashboard/HTML surfaces display a redaction/unavailable note instead of embedding a screenshot. Blocked/unavailable browser runs never fabricate screenshots. This policy is documented for deterministic handling; pixel-level secret OCR/detection is out of scope.
